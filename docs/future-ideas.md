## Future Feature Ideas (don't impliment)

### Handoff Notes
- Record where you left off for each project.
- Capture the current task, known problems, and next step.
- Associate notes with a branch and commit.
- Make notes available on another Mac.
- Show the latest handoff note when resuming a project.

### Workspace Groups
- Organize repositories into groups such as Work, Personal, or Client.
- Review and sync a selected group.
- Resume a group on another Mac.
- Filter the dashboard and repository list by group.

### Open Project
- Open a repository in a preferred editor.
- Open a terminal at the repository folder.
- Reveal a repository in Finder.
- Open the repository's remote hosting page.
- Configure preferred applications per project.

### Activity
- Record syncs, WIP commits, pushes, failures, and cleanup actions.
- Show activity across all repositories or for a single project.
- Record the branch and commit successfully pushed.
- Provide clear failure details and relevant retry actions.
- Make it easy to verify what was preserved remotely.

### Machine Awareness
- Show which Mac last synced a project using recorded sync activity.
- Display the branch, commit, and time associated with that sync.
- Compare the current checkout with the last recorded handoff.
- Indicate when another Mac's status is unknown or out of date.

### Automation
- Schedule repository checks and end-of-day reminders.
- Enable automatic sync per repository.
- Configure how newly discovered or untracked files are handled.
- Notify users when sync fails or needs attention.
- Show the last run and next scheduled check.

### Cleaner
- Show development storage usage by project and category.
- Find regenerable build output, dependency folders, and caches.
- Identify abandoned checkouts for review.
- Preview recoverable space before removing anything.
- Explain why each item is eligible for cleanup.
- Show the likely cost of downloading dependencies or rebuilding.
- Distinguish regenerable files from unique local work.
- Block checkout cleanup when uncommitted or unpushed work is detected.
- Allow users to exclude projects or folders from cleanup.
